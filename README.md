# Tribal Scholar AI

> ⚠️ **HACKATHON PROTOTYPE / DEMO** — This is NOT an official Government of India or Ministry of Tribal Affairs application. This project was built for demonstration purposes at a hackathon.

## AI-enabled Scholarship and Fellowship Management System

A digital platform to manage the complete lifecycle of scholarship and fellowship applications for Scheduled Tribe students, built for the Ministry of Tribal Affairs (MoTA) hackathon.

### Supported Schemes (Demo)

- **NFST** — National Fellowship for Scheduled Tribes
- **NOS** — National Overseas Scholarship

### Tech Stack

| Layer | Technology |
|---|---|
| Frontend | Next.js, TypeScript, Tailwind CSS |
| Backend | Next.js API Routes |
| Database | PostgreSQL + Prisma ORM |
| Charts | Recharts |
| AI/OCR | Modular service (mock for MVP) |

### Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
